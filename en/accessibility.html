Accessibility Statement

Last updated: May 29, 2026

Commitment to Accessibility

Jan-Erik Andersen is committed to making the website jan-erik-andersen.de accessible and usable in the spirit of the Web Content Accessibility Guidelines (WCAG). Where the German Accessibility Strengthening Act (Barrierefreiheitsstärkungsgesetz - BFSG) applies to individual digital services, its requirements are considered in implementation and consulting work.

Conformance Status

This website has been checked through automated tests and manual WCAG 2.2 AA-oriented spot checks. According to the current internal state, it is largely accessibility-friendly, but no full external WCAG or BFSG audit has been performed. This statement is therefore not a formal conformance certification.

  • Perceivable: High contrast ratios, semantic HTML, clear heading hierarchy
  • Operable: Keyboard-accessible navigation and interactive areas, skip link to main content, visible focus outlines, and a native checkbox-based dark-mode toggle
  • Understandable: Clear language (lang="en"), logical content structure, consistent navigation
  • Robust: Valid HTML5, structured data (JSON-LD), semantic structure for assistive technologies

Technical Specifications

The accessibility of this website is based on the following technologies:

  • HTML5 (validated)
  • CSS3 with dark mode support (prefers-color-scheme)
  • JSON-LD for structured data
  • ARIA attributes for enhanced semantics
  • JavaScript optional (core content works without JS, interactive features like the advisor funnel require JS)

Known Limitations

The current iteration intentionally stays minimal. Known notes:

  • Images include alt text, no video content present
  • There is no server-side contact form; contact is handled by email, phone, or the external LinkedIn page
  • Interactive areas such as the project compass, mobile menu, and dark mode use JavaScript
  • The manual dark-mode toggle uses a native checkbox, JavaScript is only used for persistence (localStorage)
  • An external screen reader test with multiple assistive technologies is still outstanding
