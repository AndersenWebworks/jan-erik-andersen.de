Erklärung zur Barrierefreiheit

Stand: 29. Mai 2026

Bekenntnis zur Barrierefreiheit

Jan-Erik Andersen ist bestrebt, seine Website jan-erik-andersen.de barrierearm und im Sinne der Web Content Accessibility Guidelines (WCAG) nutzbar zu gestalten. Soweit das Barrierefreiheitsstärkungsgesetz (BFSG) für einzelne digitale Dienstleistungen einschlägig ist, werden die Anforderungen bei Umsetzung und Beratung berücksichtigt.

Konformitätsstatus

Diese Website wurde automatisiert und manuell stichprobenartig WCAG 2.2 AA-orientiert geprüft. Sie ist nach aktuellem internen Stand weitgehend barrierearm, ein vollständiges externes WCAG- oder BFSG-Audit liegt jedoch nicht vor. Die Aussage ist deshalb keine formelle Konformitätszertifizierung.

  • Wahrnehmbar: Hohe Kontrastverhältnisse, semantisches HTML, klare Überschriftenhierarchie
  • Bedienbar: Skip-Link zum Hauptinhalt, Tastaturbedienung der Navigation und interaktiven Bereiche, sichtbare Fokus-Indikatoren sowie ein per Checkbox steuerbares Dark-Mode-Element
  • Verständlich: Klare Sprache (lang="de"), logische Inhaltsstruktur, konsistente Navigation
  • Robust: Valides HTML5, strukturierte Daten (JSON-LD), semantische Struktur für assistive Technologien

Technische Spezifikationen

Die Barrierefreiheit dieser Website basiert auf folgenden Technologien:

  • HTML5 (validiert)
  • CSS3 mit Dark-Mode-Support (prefers-color-scheme)
  • JSON-LD für strukturierte Daten
  • ARIA-Attribute für erweiterte Semantik
  • JavaScript optional (Kerninhalt funktioniert ohne JS, interaktive Features wie der Berater-Funnel benötigen JS)

Bekannte Einschränkungen

Aus den internen Audits ergeben sich aktuell keine priorisierten offenen Einschränkungen. Hinweise:

  • Bilder haben Alt-Texte, keine Videos vorhanden
  • Es gibt kein serverseitiges Kontaktformular; Kontakt läuft per E-Mail, Telefon oder externe LinkedIn-Seite
  • Interaktive Bereiche wie Projekt-Kompass, Mobile-Menü und Dark Mode nutzen JavaScript
  • Dark-Mode-Umschaltung erfolgt per nativem Checkbox-Element, JavaScript wird für die Persistenz (localStorage) verwendet
  • Ein externer Screenreader-Test mit verschiedenen assistiven Technologien steht noch aus
